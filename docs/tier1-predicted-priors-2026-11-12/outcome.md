## What the coin experiment actually used

The coin is a real object already present in the external ECUST photographs, with diameter25mm documented by the [dataset author](https://raw.githubusercontent.com/Liang-yc/ECUSTFD-resized-/59603e70c99807af46df9af3c2c507995fdd0029/README.md). It was not inserted into user photographs. The previous scale experiment used author-annotated food/coin boxes, not an implemented automatic coin detector.

ArUco/ChArUco is a separate, untested coded-marker direction in the saved specification. ArUco supplies identifiable ordered corners and IDs; pose estimation requires known physical marker size and camera calibration. See [OpenCV ArUco documentation](https://docs.opencv.org/4.10.0/d5/dae/tutorial_aruco_detection.html) and [ChArUco calibration](https://docs.opencv.org/4.9.0/da/d13/tutorial_aruco_calibration.html). These features make coded markers useful for automatic localization; neither a coin nor a flat marker alone supplies food height/volume. No specific asset called `ArUco2` was found or implemented here. The earlier mass-only coin-box experiment did not evaluate this marker design, pose calibration or volume reconstruction, so a broad conclusion rejecting reference objects was not justified.
